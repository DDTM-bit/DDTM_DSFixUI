The game is Dark Souls PTDE(Prepare to Die Edition). 
DSfix need a good GUI so this is my work for configuring DSfix in an easily understandable and professional manner.
This is only for my DSFix v3.0 imporvements and fixes project. The app edits DSfix.ini, DSfixKeys.ini and DarkSouls.ini

Features: Dynamic resolution detection, browse folder paths, visual change tracking, optimized settings, default settings.

How to use it: Place it in the Dark Souls game folder next to DSfix.ini.
